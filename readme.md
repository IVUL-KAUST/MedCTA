# MedCTA project page

This site adapts the provided project-page template for **MedCTA: A Benchmark for Clinical Tool Agents**.

## Local preview

```bash
python app.py
```

Then open http://127.0.0.1:5000/ in a browser.

## Replace screenshot placeholders

The paper screenshots used on the page are stored in `static/img/medcta/`. To replace them with original exported figures, keep the same file names:

- `benchmark_comparison.png`
- `curation_pipeline.png`
- `query_transformation.png`
- `trajectory_annotation.png`
- `metrics_correlation.png`
- `results_tables.png`
- `failure_analysis.png`
